## ✧ Tentang Saya

Halo! Saya **Zahri Adnan Nasution**, mahasiswa **Manajemen Informatika di Politeknik Negeri Padang (PNP)**.

Saya memiliki ketertarikan di bidang teknologi, pemrograman, dan pengembangan perangkat lunak. Saya senang membuat solusi digital, mengembangkan sistem informasi, serta mempelajari berbagai teknologi baru.

Saya percaya bahwa setiap proyek merupakan kesempatan untuk belajar, mengembangkan kemampuan, dan menciptakan sesuatu yang bermanfaat.

- 🎓 Mahasiswa Manajemen Informatika PNP
- 💻 Tertarik pada pengembangan web dan aplikasi
- 🗄️ Mempelajari manajemen database dan perancangan sistem
- 📱 Mengembangkan kemampuan mobile development dengan Flutter
- 🐳 Mempelajari Docker dan deployment aplikasi
- 🚀 Terus belajar dan mencoba hal-hal baru
